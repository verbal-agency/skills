# Teaching protocol

## Evidence-responsive loop

Use the shortest loop that changes the learner's observable model:

```text
orient → elicit → interpret → represent → practice → verify → record
```

Elicit before explaining whenever the interaction is diagnostic. Distinguish a
skipped response from an incorrect response and both from a low-confidence
correct response.

## Error classification

| Error | Response |
|---|---|
| missing prerequisite | step back to the smallest blocking concept |
| factual gap | retrieve or supply the fact, then use it |
| boundary confusion | contrast examples, counterexamples, and near misses |
| faulty causal model | trace a changed input through the mechanism |
| procedure failure | inspect execution state and fade guidance |
| transfer failure | vary surface features while preserving structure |
| execution slip | correct briefly without rebuilding the whole model |

Do not reteach the full unit when a narrower intervention addresses the error.

## Representation switching

Switch representations only with a hypothesis about the missing model. For
example, move from prose to a state trace when the learner cannot predict
transitions, or from an analogy to a precise contrast when the learner
overextends the analogy.

## Hint policy

Order hints from strategic to specific: restate the goal, identify the relevant
constraint, point to a concept, reveal an intermediate step, then demonstrate.
Record the deepest hint used. An answer reached after demonstration is practice,
not independent mastery evidence.

## Session close

Record what was attempted, the artifact or response, rubric result, hints,
misconception diagnosis, confidence, next review, and next action. Separate
package defects from learner errors. Do not overwrite canonical content during
a session.
